# Getting Started

Learn how to obtain an API key, install the `cotbias` package, configure your environment, and perform your first request.

!!! note "Documentation in Progress"
    This guide is currently being drafted as part of our Phase 2 documentation rollout.

## Overview
To start using the COT Bias Terminal Quant API:
1. Obtain an API key from the [COT Bias Terminal](https://cot-bias-terminal.com).
2. Set the `COT_API_KEY` environment variable or pass `api_key` directly to `CotClient`.
3. Query timeseries, inference, screeners, and contract lists.
